# Transformer Explainer: Learning LLM Transformers with Interactive Visual Explanation and Experimentation

Transformer Explainer is an interactive visualization tool designed to help anyone learn how Transformer-based models like GPT work. It runs a live GPT-2 model right in your browser, allowing you to experiment with your own text and observe in real time how internal components and operations of the Transformer work together to predict the next tokens. Try Transformer Explainer at https://te-anonymized.github.io/transformer-explainer-demo.<br/><br/>

## How to run locally

#### Prerequisites

- Node.js v20 or higher
- NPM v10 or higher

#### Steps

```bash
git clone https://github.com/te-anonymized/transformer-explainer-demo.git
cd transformer-explainer-demo
npm install
npm run dev
```

Then, on your web browser, access http://localhost:5173.
